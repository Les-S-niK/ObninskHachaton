# Кейс 03. Агроэпидемия: останови заражение теплицы

## Описание

Интерактивная модель распространения условного заболевания среди растений в теплице. Пользователь задаёт начальные заражённые растения, запускает симуляцию на N условных дней и сравнивает результаты с разными мерами защиты.

## Основные возможности

- Сетка теплицы N×N.
- Отображение состояний растений: здоровое, заражённое, удалённое и выздоровевшее.
- Выбор начальных заражённых растений.
- Симуляция распространения заболевания на протяжении N условных дней.
- Применение как минимум двух мер защиты с разным эффектом и условной стоимостью.
- Сравнение сценариев по числу заражённых и сохранённых растений.
- Повторяемость эксперимента при одинаковых исходных условиях.
