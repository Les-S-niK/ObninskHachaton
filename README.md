# Агроэпидемия — симулятор распространения заражения в теплице

Клеточный автомат SIR-подобной модели ( мат. модель распространения инфекционных заболеваний )
на сетке: заражение распространяется по соседству Мура ( 8 соседей ), часть больных выздоравливает,
часть погибает.
Поверх модели есть **живая сессия** (шаг по дням + вмешательства от пользователя)
и **сравнение** базового сценария со сценарием вмешательств при одинаковом seed.

---

## Быстрый старт

В качестве пакетного менеджера используется UV.

```bash
uv sync
uv run obninskhachaton
```

Приложение поднимется на `http://0.0.0.0:80`
( См. AppSettings в config.py )

---

## Что делает приложение

- **Сетка** `rows × cols` (10…50), у каждой клетки — растение.
- **Состояния клетки:** `HEALTHY (0)`, `INFECTED (1)`, `RECOVERED (2)`, `REMOVED (3)`.
- **Соседство Мура** — 8 соседей; за край сетки заражение не переходит.
- **Начало симуляции:** 1–3 очага заражения (все `INFECTED`), остальные `HEALTHY`.
- **Шаг = один день.** Есть режим живой сессии (шаг/пауза/запуск),
  вмешательства пользователя и сравнение двух сессий.

---

### Один день (шаг)

1. **Плановые вмешательства этого дня** применяются **до** распространения.
2. Делается **ровно два массива случайных чисел** `rows × cols`
   сценарии с одинаковым `seed` сопоставимы.
3. **Новые заражения.** Для каждой здоровой клетки считается `k` — число
   заражённых соседей Мура, **с учётом маски изоляции** (заражение не проходит
   между клетками по разные стороны границы изоляции). Вероятность заразиться:
   `1 − (1 − infection_prob)^k`; если бросок меньше — клетка становится `INFECTED`.
4. **Исходы болезни** для клеток, заражённых **на начало дня** (свежие
   заражения этого дня не выздоравливают и не погибают в тот же день):
   - с вероятностью `recovery_prob` → `RECOVERED`;
   - иначе с вероятностью `removal_prob` → `REMOVED` (гибель от болезни);
   - иначе остаётся `INFECTED`.
5. Кадр `day` фиксирует итог дня. Кадр `day = 0` — исходная сетка.

### Вмешательства

- `remove_cell` — удаляет **одну** клетку в `coord`, **независимо от её
  состояния**. Если клетка уже `REMOVED` — no-op, стоимость `0`.
- `isolate_zone` — включает круг радиуса `radius` в маску изоляции
  (постоянно). Оплачиваются **только впервые изолированные** клетки.

Изоляция **сама растения не удаляет** — она только блокирует заражение
через границу зоны и действует до конца эксперимента.

### Стоимость

- Удаление: `cost_per_plant` за успешное удаление.
- Изоляция: `cost_per_cell × newly_isolated`.
- Накопленная стоимость — `cumulative_cost` (в метриках поле `cost`).

### Seed

При одинаковом `seed` и одинаковых параметрах динамика воспроизводима;
вмешательства поток случайности не сдвигают.
